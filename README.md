# BacklinkPilot

Automated backlink building toolkit for indie SaaS makers.

## Overview

BacklinkPilot helps indie makers build high-quality backlinks through automation. It handles directory submissions, profile creation, and content distribution across platforms.

## Built For

Originally built to support [Popcorn AI](https://popcornai.art) — an AI-powered image-to-video tool for content creators.

## Features

- Multi-platform profile creation
- Directory submission automation  
- Content distribution pipeline
- Backlink health monitoring
- DR tracking and analytics

## Tech Stack

- Next.js + TypeScript (dashboard)
- Python (automation scripts)
- Playwright/Patchright (browser automation)
